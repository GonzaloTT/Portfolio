# Portfolio Design Guidelines

## 1. Objective

Build a professional, responsive developer portfolio for
Gonzalo Magaña Segovia.

The portfolio must follow the Stitch references located at:
docs/design/references/

These images are visual references, not exact implementation specifications.
Content, layout and responsive behavior may be refined when necessary.

## 2. Design system

Colors:
- Background: #080B09
- Secondary background: #101612
- Surface: #141A16
- Neon green: #B6FF3B
- Accent green: #38D985
- Primary text: #F2F6F1
- Secondary text: #9AA69D
- Border: #28362D

Typography:
- Headings: Space Grotesk
- Body: Inter
- Technical labels: JetBrains Mono

Style:
- Minimalist dark theme
- Selective neon-green accents
- Clear hierarchy
- Generous spacing
- Accessible contrast
- Responsive layouts

## 3. Pages

Only three main pages:

1. Home (/)
2. Experience (/experience)
3. Connect with Me (/connect)

## 4. Navigation

Header:
- Home: scroll to top
- About: scroll to About on Home
- Experience: navigate to /experience
- Projects: scroll to Projects on Home
- Skills: scroll to Skills on Home
- Contact: scroll to Contact on Home
- Connect with Me: navigate to /connect

Navigation from other pages must correctly return to
the corresponding section on Home.

## 5. Home sections

Order:

1. Hero
2. About
3. Selected Work
4. Tech Stack
5. Let's Build Something Together
6. Footer

Do not add separate AI Agent or Networking sections.

## 6. Projects

Use one horizontal carousel, not a static project grid.

Projects:

1. LiftIA
2. GymFinder
3. Around the U.S.
4. KGC ERP / Pricing SPA
5. Gutterkel
6. XVR
7. New Pig Mexico

Each project card includes:
- Large image placeholder
- Project name
- Short description
- Technology badges
- GitHub link when available
- Live project link when available

Carousel requirements:
- Previous/next controls
- Slide indicators
- Touch/swipe support
- Keyboard accessibility
- Responsive layout

Do not invent links, performance metrics or achievements.

## 7. Experience

Show professional experience at King Global Cargo.

Focus:
- Internal software development
- ERPNext and Frappe
- Frontend interfaces
- Business process digitalization
- IT support
- Microsoft 365
- Technical documentation

Keep content concise.

Do not include fictional dates, metrics, certifications
or technology achievements.

## 8. Skills

Use a compact section grouped into:

- Frontend
- Backend & Data
- Mobile
- Tools & Design

Avoid large descriptions and proficiency percentages.

## 9. Connect with Me

Minimal connection page including:

- Professional digital identity
- QR placeholder
- Profile identifier
- Copy ID action
- Copy profile URL action
- Input to connect another profile

The real connection system will be implemented later.

Do not add AI chat interfaces or networking dashboards.

## 10. Images and animations

Use intentional image placeholders.

Real project screenshots and professional photography
will be added later.

Do not generate fictional project images.

Animations will be implemented in a later phase.
Keep the initial UI clean and ready for future motion.

## 11. Responsive design

Use the desktop and mobile references.

Target desktop: 1440px
Target mobile: 390px

Maintain:
- Accessible navigation
- Readable typography
- Responsive project carousel
- Mobile-friendly controls
- Consistent spacing

## 12. Content integrity

Never invent:
- Employment dates
- Project URLs
- Professional achievements
- Performance metrics
- Certifications
- Completed features that remain in development

Use explicit placeholders when necessary.
