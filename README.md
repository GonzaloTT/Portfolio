# Gonzalo Portfolio

Professional portfolio and AI-powered networking platform.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Motion

### Backend
- Node.js
- Express
- TypeScript

### Database
- Supabase (PostgreSQL)

### AI
- Google Gemini API

## Project Structure

- apps/web: Frontend application
- apps/api: Backend and agent orchestration
- packages/shared: Shared types and schemas
- supabase/migrations: Database migrations
- docs: Architecture, design, and agent documentation

## Development

The project uses npm workspaces.

Frontend, backend, and shared package configuration will be added during implementation.
